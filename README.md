# 🎯 Guess the Number Game

A fun and interactive number guessing game built using **HTML, CSS, and JavaScript**. Challenge the computer, earn points, and see who wins in a Best of 5 match!

##  How to Play

1. The computer randomly selects a secret number between 1 and 10.
2. Enter your guess in the input field.
3. Click the **Guess!** button.
4. If your guess is correct, you win the round.
5. If your guess is incorrect, the computer wins the round.
6. The first player to reach 3 points wins the Best of 5 match.
7. Click **Next Round** to continue playing.
8. Use **Reset Game** to start a new match.

## Features

- Random number generation.
- Player and computer score tracking.
- Best of 5 game mode.
- Sound effects for winning and losing.
- Final winner screen.
- High score saved using localStorage.
- Responsive and colorful design.
- Reset game functionality.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser localStorage
- Web Audio API
